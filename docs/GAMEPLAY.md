# 《深渊回响》玩法指南 / Abyss Echo Gameplay Guide

## 核心循环 / Core Loop

```
搜索房间 Search → 战斗/事件 Combat/Event → 深入 Descend → 每 3 层 Boss → 第 12 层深渊核心 → 最终战/结局
```

每层可探索 **2 个房间**（战斗/事件/营地/宝箱/陷阱），搜刮完毕即可深入下一层。第 3/6/9/12 层为 Boss 层（**Boss 战无法逃跑**）。

Each floor offers 2 rooms (combat/event/camp/chest/trap), then you descend. Floors 3/6/9/12 hold bosses — **you cannot flee boss fights**.

## 战斗系统 / Combat

- **攻击 Attack**：基础伤害 = ATK × 浮动 − 敌方 DEF×0.6；暴击率 = 5% + LCK×1%（×1.7 伤害）
- **防御 Guard**：本回合防御 ×2（格挡），下回合我方优先出手
- **技能 Skills**：消耗 MP，有冷却；推荐循环：撕裂(流血)→重击→(Boss)守护
- **道具 Items**：战斗中直接使用（药水/符文/圣水）
- **逃跑 Flee**：成功率 = 55% + SPD 差值加成；成功则离开该房间
- **异常状态**：中毒/流血/灼烧（每回合 DOT）、虚弱/狂暴/守护/祝福（属性修正）
- **Boss 二阶段**：生命低于 50% 时进入狂暴形态（攻击 +15%，有专属告警与特效）

## 成长系统 / Growth

- 经验需求：Lv.n → 40 + 30×(n−1)；击杀后自动升级，回满固定百分比
- 每级：HP +20 / 攻击 +4 / 防御 +2 / 速度 +1 / 魔力 +6
- 装备槽：武器 / 护甲 / 饰品（三槽，铁匠 9 折铸造）
- 转生（深渊刻印）：达成任一结局后获得刻印（属性 +4%/级、金币 +5%/级、无尽模式解锁）；每刻印敌人 +3%

## 进程里程碑 / Milestones

| 区域 | 深度 | 要点 |
|---|---|---|
| 浅层 | 1–3 | 熟悉战斗，攒药；3 层 Boss 格鲁尔（毒） |
| 中层 | 4–6 | 敌人换挡；6 层女王莫尔格（流血）→ 击杀卡拉泽斯后开启深渊核心 |
| 深层 | 7–9 | 精英怪常见；9 层铁心（超高防，用流血/连斩） |
| 深渊 | 10–12 | 12 层虚空领主卡拉泽斯；击杀后「深渊核心」开启 |
| 核心 | 13 | 深渊之主·奥伯斯（火焰）；击败 = 结局，或集齐碎片得真结局 |

## 真结局路径（真相碎片 ×3） / True Ending (3 Fragments)

1. **其一** — 污秽祭坛事件（触碰碎片）
2. **其二** — 深渊雕像事件（掌心碎片）
3. **其三** — 击败深渊之主·奥伯斯
   → 集齐后击败奥伯斯：选择「封印深渊」→ 结局：深渊之眼（真结局）

## 每日挑战 / Daily Challenge

每天 08:00 UTC 更换规则组合（2–3 个修饰符），独立存档，死亡即止。标题页显示今日最佳与近 7 天历史。

## 无尽深渊 / Endless Abyss

转生一次后解锁。无层数上限，每层敌人 +3%；每 10 层遭遇「回响 Boss」（属性大幅强化、额外掉落）。深度与回响击杀计入统计与成就。

## 常见问题 / Tips

- 金币优先买：大治疗药水 > 守护符文 > 力量符文；Boss 前保持 2 瓶以上药
- **锻造强化**：铁匠铺可将已装备物品强化至 +5（每级 +10% 属性，费用 200×级 金币；强化随物品绑定，转生保留）
- 圣水/净化可解虚弱；中毒药水叠加 3 回合伤害可观
- 精英怪（🌟）：15% 概率，双倍奖励必掉物品；精英猎杀令任务可顺路完成
- 委托任务的黄金任务是「财富试炼」（金币 400），攒钱时顺路完成
- 每日挑战的「狩猎之日」（精英×2）配合精英猎手成就最快
